# 对话操作插件验证记录

范围：移除常驻“提取表格”按钮，新增 Agent 主动建议、用户确认执行和统一插件注册层。

## 实现与审查

- 注册真实 DSH 工具 `propose_conversation_action`，生产逻辑没有关键词匹配或固定轮数触发。
- 首个执行插件为 `extract_table`；没有注册尚不可用的设计调整或 DLL 计算工具。
- 单轮最多一项建议，提取执行轮不再次推送建议；直接提交 `intent: extract` 不能绕过确认。
- 后台校验所属会话、待确认状态、已更新的上下文和执行前条件；重复或并发确认最多执行一次。
- 提议工具不进入执行器；确认状态刷新失败时不执行。失败和中断状态不自动重试。
- 拒绝记录在会话内，不调用模型；新输入令旧建议失效。用户和助手普通文字不能伪造插件状态。
- 主代理审查了状态转换、执行边界、DOM 文本渲染、失败处理和扩展入口；未使用子代理。
- 本轮使用 `ui-ux-pro-max` 和 Browser 技能检查前端交互。新增生产模块均少于 300 行，检查涉及的函数均不超过 50 行。
