# 翅片接入 MCHE Agent 验收

2026-09-09，Windows，当前 `dsh_mche_agent` 工作区。范围为用户要求的翅片选型接入；继续使用现有 DSH 循环和翅片目录，不涉及 DLL 计算或装配匹配规则。

## 实现

- 四个工具：`fin_search`、`fin_get`、`fin_recommend`、`fin_propose_selection`。HTTP 增加对应入口及用户专用的 `confirm-fin`，模型不能代确认、跨会话或覆盖几何。
- 四分区 164 型号，精确名称、Code 一对多、尺寸/范围筛选、零开窗角度/个数；主表宽度与料宽、焊前后高度与槽尺寸分开。推荐保留目录顺序和满足/不满足/未知依据。
- 翅片条件、候选、建议、确认与快照；`selections.fin` 与 `selections.tube` 并存。部件独立版本防止条件变更误撤销另一部件建议；共享工况变化重查两个部件。过期、重复、跨部件/会话确认拒绝。
- 确认时按目录摘要读取完整记录，保存型号、Code、分区、几何、单位依据、原单元格、未标注列和待核对项；目录变更不覆盖历史。旧扁管记录读取时兼容补齐空翅片状态，不回写历史文件。
- 右侧详情支持部件切换、输入核对、Code/型号查询、候选比较、型号确认、来源与参数准备；每轮模型读取当前两部件确认状态。
- 参数增加 `finGeometry`，明确数值按单位转换，范围/上限保留原文；继承单位未核实时不转换成计算值。状态分开显示扁管逻辑参数、翅片核心几何、装配与 DLL 就绪情况。

## 浏览器验收

使用隔离的 `node scripts/ui-fixture.mjs`、真实 Web App 和本地确定性模型，经 Chrome 实际交互验证：

1. 输入 A01S 扁管与主表翅片条件，模型调用六个工具，出现独立蓝色结果链接。
2. 核对并确认 B01，再切换扁管确认 A01S；先确认翅片不丢失待处理的扁管建议。
3. 在两个部件输入页分别确认草稿，生成包含扁管截面、管长/管数/管间距、翅片几何的参数包；确认值与原表单元格对应。

5. 刷新页面并打开历史蓝色链接，恢复 A01S 与 B02 的已确认状态和当前尺寸。
6. Code `310150` 返回 B0f（主表）和 B150（穿管模具），两者分别显示尺寸和来源说明；没有合并。
7. 参数表保留 `1.1~1.3` 与 `≤0.6` 原文及 I7/J7 来源，计算数值保持未知。截图检查右侧布局，页面 warning/error 日志为空。
