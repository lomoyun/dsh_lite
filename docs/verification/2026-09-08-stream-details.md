# 流式正文与右侧详情验收

## 行为

- `/api/chat`、`/api/actions/decide` 接受 SSE，仍兼容原 JSON 调用。接入原生 `session/event` 的 `text-delta`，没有模拟打字效果。
- 公开正文保留同轮全部模型步骤；历史沿用同一投影，Token 整轮只汇总一次。流式和历史未完成回复有明确提示。
- 表格、代码和工具结果以蓝色下划线按钮打开右侧详情。工具参数、推理和请求头不发送到页面。
- 建议链接由真实工具结果产生；打开仅查看，在详情中确认才执行。操作 ID 仍为 `extract_table`，显示名称改为“整理参数表”。
- 表格详情支持编辑、撤销、复制、确认发送；关闭抽屉保留编辑状态，切换会话仍检查未发送修改。
- 未改持久化模块、日志格式、根配置、依赖或 DLL 计算。
