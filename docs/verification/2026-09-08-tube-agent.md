# 扁管选型 Agent 接入验收

执行来源为 [用户确认计划](../tube-agent-plan.md)。其中 Plan Mode 描述保留为原文；本轮在实现模式执行。
使用单主代理，保留原有未提交改动，没有提交、推送、修改扁管目录或调用真实 DLL。

## 交付范围

- `packages/dsh-mche/`：只读目录服务、草稿与确认值、版本化会话方案、候选比较、建议、不可变几何快照、逻辑参数准备。
- 注册7个原生 Agent 工具；不增加逐步流程状态机，不提供模型确认工具。浏览器确认后，下一轮收到最新服务端方案摘要。
- 右侧详情复用蓝色链接，支持输入核对、目录查询、候选比较、型号确认、已选几何、参数及来源。
- 确认绑定会话、建议/核对令牌、版本及目录摘要。条件变化重查约束，失效确认不会自动复活。
- 参数包明确 `scope=tube-logical-only`，分别表示型号确认、扁管参数完整、DLL映射未就绪。
- 默认与实际 profile 已接入；原服务需要重启加载插件，本轮没有终止用户原服务。

工程流程采用 executing-plans、test-driven-development、ui-ux-pro-max、verification-before-completion；浏览器使用 control-in-app-browser。
按单主代理约束完成代码自审，没有独立第二审查者。自审补充了未知约束失效、完整工具响应分页、筛选链接展示原查询、参数键/单位一致性及未保存输入保护。

## 浏览器验证

使用真实Chrome页面、真实DSH后端、本地确定性模拟模型；没有调用外部模型或改用户真实会话。

Windows隔离服务：

- 语言输入宽16mm、高1.8mm、长500mm、20根、间距10mm，自动执行5个工具并生成蓝色链接。
- 核对输入、查看A01S和A192S1的满足/不满足/未知项，确认A01S，显示目录几何和总表来源单元格。
- 准备参数，显示型号已确认、扁管参数完整、DLL映射未就绪及4类映射阻塞。
- 刷新后状态恢复。改管长只清除管长确认；改管宽到25.4mm使原型号确认失效。
- 未保存输入时切换详情被阻止，保存后可继续。
- 第二个新会话的表格发送遇到502，页面保留未发送草稿；这段Windows表格流程没有判定通过。

Linux隔离服务补验：

- 从剪贴板粘贴5行参数表，发送后真实Agent产生草稿、目录查询、精确型号、候选比较和建议。
- 查询结果展示原范围条件（15到16mm、高1.8mm）及11个匹配型号，保留特殊孔型说明。
- 完成输入确认、A01S型号确认、参数准备，管长0.5m、管数20、间距0.01m，几何字段有原单位和单元格来源。
- 刷新后恢复同一表格会话及详情链接；375×812窄屏页面/抽屉宽375，无页面横向溢出；812×375横屏未溢出。
- 参数表显示值最多12位有效数字，完整参数包保留原数值及换算规则，不改目录缓存精度。

浏览器结果证明这条固定样例的交互闭环，不代表真实外部模型的提取/推荐准确率。
