# 附件交互验证记录

日期：2026-09-08。范围：将即时上传表格改为“＋ 附件”、拖放、弹窗与发送时上传。

## 行为

- 点击“＋ 附件”打开带拖放区域的原生对话框，可一次选择多个 Excel/CSV。
- 拖入聊天、输入框或附件弹窗时加入同一待发送队列；拖入页面时显示放置提示。
- 选择或拖入文件不发出网络请求；点击发送后依次上传并解析，全部成功后才提交聊天。
- 附件卡片包含文件名、大小、待发送/正在解析/已解析/失败状态，并支持发送前移除。
- 失败保留附件与输入；重复发送复用本轮已解析结果。成功发送清空队列。
- 内容识别区分 XLSX ZIP 与 XLS CFB，CSV 自动识别编码；Excel 内容与扩展名不同时提示。
- 仅支持现有 Excel/CSV，其他文件明确拒绝；没有新增数据库结构、依赖或持久化格式。
