# 扁管选型接入 Agent：自主调用工具，后端校验数据

当前会话仍处于 Plan Mode，尚不能修改代码。以下为合并本次讨论后的最终实施方案。

## 1. 交互与流程

保留现有 Agent 循环，不实现强制逐步执行的流程状态机。

Agent 根据用户意图自由安排查询、比较、推荐、补充条件和更换型号。支持直接指定型号、先看候选后补工况，以及在选型过程中讨论其他问题。

草稿条件可以用于初步推荐，明确标注尚未确认的依据。正式计算只使用已确认参数和已确认型号的几何快照。

## 2. 业务服务与工具

新增 `packages/dsh-mche/`，加载现有扁管目录，注册：

| 工具 | 职责 |
|---|---|
| `mche_case_get` | 获取输入、确认情况、已选部件和缺项 |
| `mche_case_update_draft` | 更新输入草稿，保留单位和来源 |
| `tube_search` / `tube_get` | 筛选目录、查询精确型号 |
| `tube_recommend` | 根据当前条件推荐，列明满足、不满足和未知项 |
| `tube_propose_selection` | 创建待用户确认的型号建议 |
| `mche_prepare_calculation` | 准备参数及来源，返回计算阻塞项 |

工具按操作所需条件独立校验，不要求先调用其他工具。条件不足时返回具体缺项，由 Agent 决定下一步。

推荐采用明确的尺寸约束和可验证规则；不虚构性能、成本或供货评分。等价候选并列展示，不强行选出“最佳”。

## 3. 持久化与用户确认

每个会话默认维护一个当前方案，保存输入草稿、确认值、候选建议、`selections.tube` 和入参准备状态，刷新及重启后恢复。

复用蓝色链接和右侧详情，增加输入核对、候选比较、型号确认及已选尺寸展示。确认请求绑定会话、建议和版本，防止重复确认或确认过期数据。

用户确认型号后，后端从目录读取并保存不可变几何快照，包含型号、目录摘要、单位和来源；不接受模型提供的尺寸覆盖目录。

修改条件后重新检查相关约束，失效的确认需要重新完成。目录更新不静默替换历史快照。

33 个待核对型号保持可查询，明确尺寸矛盾和未知信息分别展示。选择型号不代表问题已解决，也不自动获得计算资格。

## 4. 计算接口边界

后端合并型号截面几何与用户确认的管长、管数、管间距等设计参数，输出带版本的逻辑参数包、来源和缺项。

仅按已核实的映射转换单位；孔型、周长、面积含义及编码等未核实内容明确阻塞，不猜测、不填零。

分别表示“型号已确认”“参数完整”和“DLL 映射就绪”。未来 DLL 适配器通过方案及快照引用读取数据，生成最终位置数组。

本期不调用真实 DLL、不通过试算排名、不编辑原目录，也不实现其他部件选型。

## 5. 实施与验收

按业务状态与目录服务、Agent 工具、确认页面、入参准备和端到端验证的顺序实施。

验收覆盖：

- 表格和语言输入、草稿推荐、直接指定型号、先比较后补条件。
- 连续追问、修改条件、更换型号及相关确认失效。
- 精确型号查询、范围筛选、无匹配和待核对项。
- 几何快照与目录一致、模型无法覆盖尺寸、单位转换与缺项阻断。
- 重复及过期确认、会话隔离、刷新和重启恢复。
- 浏览器完成输入、推荐、确认和查看参数全过程。

完成后如实报告验证结果；未进行真实 DLL 计算不得表述为计算链路已打通。
