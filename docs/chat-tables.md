# 对话与表格提取

本阶段在现有 DSH Lite 聊天页提供三种输入入口，沿用单 Agent 和原生会话历史。

## 使用

1. **添加附件**：点击输入框左下角“＋ 附件”，弹窗会提示“把文件拖到这里”，也可点击选择文件。
   支持 `.xlsx`、`.xls`、`.csv`，可以一次添加多个文件；也可直接拖到聊天区域或输入框中。
   选择、拖入时只在当前页面加入待发送列表，显示文件名、大小和状态，可单独移除，不会立即上传。
   点击“发送”后才上传，自动识别 Excel 内容和 CSV 编码；无需手动选择解析方式。
   全部附件解析成功后，将各工作表与本轮文字一起发给 Agent，用户消息内显示蓝色下划线表格链接，点击后在右侧核对。
   失败会保留附件和输入文字；重试复用本轮已解析的文件。成功发送后清空待发送列表。
2. **粘贴表格**：从 Excel 复制单元格区域并粘贴到输入框，自动生成草稿。
   首行作为表头；请包含完整表头。Markdown/CSV 文本也可直接作为对话内容发送。
3. **对话操作建议**：先讨论参数和目标。当 Agent 判断本阶段信息适合整理时，会在回复中展示“整理参数表 · 等待你确认”链接。
   点击链接打开右侧建议卡片，点击“确认整理”后才生成表格，也可点击“暂不执行”继续讨论。
   可以直接告诉 Agent 想整理表格，由它提出建议；卡片出现时机由模型结合上下文判断，不按固定轮数触发。
   提取需要配置可用模型。模型应保留来源原文，未提供的信息留空，结果需要人工核对。
4. **核对与发送**：点击表格链接，在右侧详情中点击“编辑表格”，修改表头和单元格，或添加、移除数据行。
   粘贴草稿通过输入框“发送”一起提交；附件解析后的用户表格或 AI 表格通过“确认并发送”作为新消息提交。
   “撤销修改”恢复原表，“放弃这组草稿”移除未提交的导入草稿。
5. **继续讨论**：模型收到确认后的表格与本轮问题；表格消息可随会话重新打开或服务重启恢复。
   未发送的附件和草稿只存在当前页面，离开页面有提示；切换项目/会话前需先发送或移除，不会转移到其他会话。

文件解析和粘贴解析无需模型，也不会调用 DLL。
正文通过真实模型文字事件流逐段显示；表格、代码和工具结果使用详情链接，推理内容与工具参数分片不进入页面。
工具调用前后的公开正文都会保留，历史按整轮显示，用量只汇总一次。流中断时标注未完成；重新打开对话核对状态。
点击详情仅查看，既不会再次读取附件，也不会自动执行工具或建议。

## 数据与限制

- 每轮最多 8 个附件；每个文件最多 5 MiB、8 个工作表；每张表最多 200 行数据、30 列。
- 每次提交最多 8 张表、6,000 个单元格（含表头）、40,000 个单元格字符；单元格最多 2,000 字符。
- 超限拒绝并提示拆分，不静默截断；聊天问题最多 8,000 字。
- 保留空白、零、重复表头、文本编号和 Excel 显示格式。Excel 已丢失的数字精度无法恢复。
- Excel 公式显示为 `=原式` 文本，解析器不执行公式。合并单元格只保留左上角内容，并显示提示。
- 工作簿内的隐藏工作表也会随附件解析和发送，并在结果中标注；不希望提交的工作表请在源文件中移除。
- CSV 自动识别先尝试 UTF-8/BOM，再尝试 GB18030；中文仍异常时可另存为 UTF-8 CSV 后重新添加。
- 自动识别覆盖 Excel/CSV。PDF、Word、图片等格式当前会明确提示暂不支持，不会当作表格猜测解析。
- 浏览器用文本节点呈现内容，不执行 HTML；上传只在内存和限时 Worker 中解析，不保存原附件。

## 实现入口

- `packages/dsh-lite-web-app/public/table-data.js`：表格结构、尺寸与数据校验。
- `public/table-format.js`：粘贴的 CSV/TSV/Markdown 解析。
- `public/table-message.js`：表格消息编码、提取指令、模型输出解析。
- `public/table-view.js`、`public/table-composer.js`：聊天内表格、编辑与粘贴。
- `public/chat-stream.js`、`public/chat-view.js`：流式接收与正文展示；`public/detail-drawer.js`：表格、代码和工具结果的右侧详情。
- `src/response-view.js`：从原生事件投影公开正文、工具详情和历史；`src/http-stream.js`：同一接口的 SSE 传输。
- `public/attachment-queue.js`：本轮附件队列、延迟上传、失败保留和解析结果复用。
- `public/attachment-composer.js`、`public/attachment-drop.js`：附件卡片、选择弹窗、拖放浮层和交互。
- `src/table-workbook.js`、`src/table-import.js`：Excel/CSV 读取与资源限制。
- `POST /api/tables/import`：原始文件体，`Content-Type: application/octet-stream`，
  `X-File-Name` 使用 URL 编码的文件名，`X-Text-Encoding` 可选。
- `POST /api/chat`：可选 `tables`，旧纯文本请求仍兼容。外部传 `intent: extract` 会拒绝，提取仅通过建议确认入口执行。
  表格形态为 `{title, source, columns: string[], rows: string[][], warnings: string[]}`。
- `POST /api/actions/decide`：提交 `{sessionId, id, decision: "confirm" | "dismiss"}`，后台验证建议所属会话和状态。
  聊天和决定接口都支持 `Accept: text/event-stream`；不提供该请求头时保留原 JSON 响应。
  SSE 的 `session` 提供会话 ID，`text` 提供本轮累计正文，`detail` 提供完成的工具结果，`done.data` 是完整响应，`error` 表示未完成。
  不新增日志格式；断连停止传输，当前 Agent 继续完成并保存。重新打开会话可恢复已保存结果。
- `src/action-plugins.js`：注册操作说明、执行前校验和执行器；接入规范见 [对话操作插件](conversation-actions.md)。

确认表格被编码为原生用户消息的一部分，历史记录不需要新增数据库或 schema。
建议保存在原生工具结果中；确认和完成状态使用原生插件消息保留。拒绝不调用模型；重复确认、跨会话和过时建议会被拒绝。
自然语言提取使用原 Agent 的当前会话上下文，不替换用户系统提示词，不新建第二个 Agent。

## 当前边界

这是对话资料整理功能。正式输入表、字段映射与必填定义尚未交付，因此本阶段不声称参数已满足计算条件，
也不输出“缺少 17 项”这类没有正式字段依据的计数。后续计算仍需正式标准表单、后端校验和 DLL 调用门禁。

## 验证

- `node --test packages/dsh-lite-web-app/test/*.test.js`：解析、结构、上传接口、错误与运行时测试。
- `node --test packages/dsh-model-config/test/runtime.test.js`：真实 Cordis/Agent + 本地模拟模型，验证表格进入模型、确认修订、会话隔离和重启恢复。
- `pnpm test`、`pnpm run typecheck`、`pnpm peers check`：仓库回归与依赖检查。
- `node scripts/ui-fixture.mjs`：隔离配置的浏览器验收环境，启动日志提供页面地址与 Excel/CSV 样例路径。
  模拟模型只验证协议与交互，不能作为真实模型提取准确率的证据。
