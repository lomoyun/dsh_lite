# MCHE Agent 现有能力与工程流程衔接改进

## Goal
工程师上传资料后复用已有数据，得到有依据的候选，保存明确草稿并找到下一步。

## Scope
按用户批准的 S1–S5 实施：读取时生成统一 guidance；区分明确约束、需求参考与已选部件的 recommendationContext；候选保存依据摘要并检测过期；Boundary 提供组合覆盖与执行支持；现有工具、模型状态和右侧页面共用指导。可选字段兼容旧历史，不迁移、不回写历史，指导不参与计算摘要。
保留自由对话、单排对话限制、用户确认和全部真实计算门禁。复用目录投影与单位/来源，不推算未验证参数。不新增优化、知识检索、计算模式或 DLL 修复；不改全局模型配置、不终止用户服务、不提交推送。

## Acceptance
- 四类待办去重，以当前 Profile/Boundary/topology 为准；旧逻辑清单仅详情；DLL 非有限结果及绑定限制仍明确。
- 无约束不擅自限定尺寸；明确草稿约束参与筛选，依据变化标过期，旧候选缺摘要要求重新比较。满足/不满足/未知/review 保留，建议理由与服务端核对分开。
- 真实需求表26条有效原值、单位、来源、主测试条件及 A10/B04 证据边界保留；不反推质量流量。
- 覆盖空/已有结构、模式切换、目录取值、失效/冲突、刷新/会话隔离、响应预算和分页及业务失败。
- MCHE 回归、受影响 Web 测试、类型检查；隔离实例用当前真实模型至少两次多轮场景及浏览器验证，保存调用/快照/截图、前后对照，确定性夹具与真实模型分开记录。真实阻塞如实记录。
